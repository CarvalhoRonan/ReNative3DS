# Contributing to ReNative3D36S

Contributions are welcome. This is a Windows WPF frontend for an independent upstream project; please keep changes scoped and documented.

1. Read `README.md` and the build guide before opening an issue.
2. Open an issue with expected behavior and reproducible steps, then submit a small pull request.
3. Build using `COMPILAR-UM-CLIQUE.cmd` on Windows x64, or use a recent .NET 10 SDK to run `dotnet build src/ReNative3D36S/ReNative3D36S.csproj -c Release`.
4. Do not silently overwrite game saves, cached versions or configuration on a failed update.
5. Preserve MIT license headers/notices and credit external contributors and dependencies.
6. For GUI changes, include screenshots (without paths or private data). For build changes, attach **redacted** output logs.

**Never commit or attach ROMs, console keys, private dumps, BIOS/firmware, real user save data, or credentials.** Do not publish other people's code or art without the right to do so. Contributors agree that their contributions to this GUI will be provided under the project MIT license, unless explicitly stated otherwise for separately licensed components.
